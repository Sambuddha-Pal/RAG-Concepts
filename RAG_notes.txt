RAG
It is the backbone of AI Data Engineering.
Retrieval Augmented Generation

Embeddings
prompt(input) -> OpenAI Model(Embedding Model) -> Embedding vector(understood by Machine)([0.2,0.4,-0.9,...]) -> OpenAI Model + Vector DB(Embeddings) ->Cosine Similarity-> Top 3 Vectors(Retrieval) -> Open AI Model+ Top 3 Vectors+ User Prompt(Augmented)-> response to user(output)(Generation)

MySQL -> Tabular Data
MongoDB-> Semi structured/json data
RAG(Vector DB)(Vector Store) -> Embeddings [1536] size of vector or dimensions on which we evaluate our prompt
RAG is an end to end process(RAG Applications)

Vector DB contains both Vectors + MetaData
Chatgpt has integrated web tools with it so even if it is not trained on current data it can web search normally
We can create our own Vector DB and provide it to the LLM model and then query it.

USER->prompt-> LLM+ Vector DB(External knowledge) -> response to user

RAG End to End Process:

Step 1: Document Input to text(PDF,Excel,File,Image)
Step 2: Chunking
Step 3: Embedding Vectors and Mappings(Each vector is mapped to it's corresponding chunk)
Step 4: Store the Embedding Vectors in the Vector DB
Step 5: Search/ semantic search(Cosine Similarity), user input will be converted into a Embedding Vector, this vector will be provide to OpenAi Model and will perform a cosine similarity with the vectors in the Vector DB and return the top 3 matched Vectors, the model will get context of the vectors and the user prompt and return the response to User
